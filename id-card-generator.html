    Print to Zebra card printer

    Opens the print dialog with one CR80 page per card side, in order (front, back, front, back…). Choose the ZC300 printer, Paper Size CR80, the orientation whose preview shows wide pages, one per card side (on the ZC300 Mac driver that is Portrait; staff cards are rotated automatically), Scale 100%, and Margins None if your browser shows it.

    Printer setup (Windows & macOS)

    One-time setup on each computer:

    1. Download the ZC300 driver from zebra.com/zc300-info (Windows driver, or the ZC100/300 macOS driver).
    2. Windows: run the installer and choose Ethernet/network, then enter the printer's IP address (port 9100 if asked). macOS: run the .pkg, then add the printer in System Settings → Printers & Scanners using its IP address and the Zebra ZC300 driver.
    3. In the driver's printing preferences, set 2-sided printing on if you print fronts and backs (2-sided ZC300 models), and pick the card orientation that keeps each card side on one wide page in the print preview (the ZC300 Mac driver calls this Portrait). Staff (vertical) cards are sent already rotated, so the same setting works for both card types. If the back comes out upside down relative to the front, toggle Flip back side 180° above (saved separately for staff and student).
    4. Print a test card. If the image is shifted, scaled, or split across two sheets, check Paper Size = CR80, the orientation that shows one wide page per side, Scale = 100%, and Margins = None in the print dialog.

    The browser prints through the installed driver, which talks to the printer at its IP address; the web page itself never connects to the printer.
